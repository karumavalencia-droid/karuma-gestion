# Karuma customer homepage redesign

Reference: https://www.mumubrasa.com/, inspected 2 November 2026. Applied principles: immersive cooking imagery, restrained navigation, generous spacing and an asymmetric food grid. Original Karuma typography, copy and layout; no reference-site images, text or code copied.

`public/images/karuma/charcoal-atmosphere-v2.webp` is an AI-generated atmospheric charcoal grill illustration, not a photograph of the restaurant. All named food photographs are existing Karuma RestoSuite assets. Menu prices and reservation links are preserved from production.

Only the public home page and scoped public CSS change. Existing reservation handling, complete menu, login and management authorization remain untouched.
